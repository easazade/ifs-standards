# Role

## Purpose

A `Role` represents a scoped collection of permissions assigned to a member. It answers who the member is acting as, where the authority applies, why the authority exists, what permissions come with it, and who can assign or remove it.

## IFS context and role

In IFS, sovereignty is non-transferable. A role is therefore not permanent rank or ownership of power. It is a delegated, scoped, auditable authority bundle that can be reviewed, limited, expired, suspended, or revoked by the legitimate affected collective or assignment rule.

The role scope applies the IFS Scope Rule: role authority only reaches the bounded context where it is valid. The role permissions describe what actions may be performed inside that scope.

## Properties

| Property               | Type                | Required | Description                                                                                                                         |
| ---------------------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `id`                   | `string(uuid)`      | Yes      | Globally unique identifier for this role.                                                                                           |
| `ifsId`                | `string`            | Yes      | Stable IFS entity identifier. Value should be `com.ifs.entity.role`.                                                                |
| `name`                 | `string`            | Yes      | Human-readable name of the role.                                                                                                    |
| `description`          | `string`            | No       | Optional human-readable explanation of what this role is for.                                                                       |
| `memberId`             | `string`            | Yes      | Identifier of the member acting through this role.                                                                                  |
| `member`               | `Member`            | No       | Member entity acting through this role.                                                                                             |
| `scopeId`              | `string`            | Yes      | Identifier of the scope where this role has authority.                                                                              |
| `scope`                | `Scope`             | Yes      | Scope entity describing where this role applies.                                                                                    |
| `permissions`          | `array<Permission>` | Yes      | Permission entities bundled into this role.                                                                                         |
| `authorityReason`      | `string`            | Yes      | Reason this member has this role authority.                                                                                         |
| `authorityEvidenceIds` | `array<string>`     | No       | Consent, vote, signature, protocol decision, or audit evidence identifiers proving the role assignment is legitimate.                |
| `assignmentPolicy`     | `object`            | Yes      | Embedded role-local policy describing who can assign or remove this role.                                                           |
| `state`                | `string`            | Yes      | Lifecycle state. Values include `drafted`, `under-review`, `active`, `suspended`, `revoked`, or `expired`.                          |
| `protocolIds`          | `array<string>`     | No       | Protocol identifiers defining assignment, permission, review, or revocation rules for this role.                                    |
| `assignedByMemberId`   | `string`            | No       | Identifier of the member who assigned this role, when assignment was performed by a member.                                         |
| `assignedAt`           | `string(date-time)` | No       | Timestamp when this role was assigned.                                                                                              |
| `revokedByMemberId`    | `string`            | No       | Identifier of the member who revoked this role, when revocation was performed by a member.                                         |
| `revokedAt`            | `string(date-time)` | No       | Timestamp when this role was revoked.                                                                                               |
| `expiresAt`            | `string(date-time)` | No       | Optional timestamp after which this role no longer applies.                                                                         |
| `createdAt`            | `string(date-time)` | Yes      | Timestamp when this role record was created.                                                                                        |
| `updatedAt`            | `string(date-time)` | Yes      | Timestamp when this role record was last updated.                                                                                   |

## Required fields

- `id`
- `ifsId`
- `name`
- `memberId`
- `scopeId`
- `scope`
- `permissions`
- `authorityReason`
- `assignmentPolicy`
- `state`
- `createdAt`
- `updatedAt`

## Relationships

- `member` references the Member entity acting through this role.
- `memberId` stores the member identifier for systems that link by ID.
- `scope` references the Scope entity where this role applies. Scope is planned through the canonical schema ID `https://ifs-standards.org/schemas/v1/entities/scope.schema.json`.
- `permissions` references Permission entities that define the actions bundled into this role.
- `protocolIds` can reference Protocol entities that define assignment, permission, review, or revocation rules.
- `assignmentPolicy` is embedded object data, not a `$ref`, because assignment and removal rules may combine members, roles, collectives, and protocol logic.
